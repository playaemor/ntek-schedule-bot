**Неофициальный Telegram-бот для автоматического отслеживания расписания занятий в НТЭК.** Бот парсит расписание с официального [сайта](https://ntek.by/index.php/uchashchemusya/raspisaniya) колледжа , автоматически проверяет обновления и уведомляет пользователей о изменениях. Включает административную панель для управления, систему обратной связи и поддержку донатов через Telegram Stars.

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.8 или выше
- Аккаунт Telegram
- Доступ к серверу или ПК для размещения бота (может работать на локальной машине)

### Установка за 5 минут

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/playaemor/ntek-schedule-bot.git
   cd ntek-schedule-bot
   ```

2. **Создайте виртуальное окружение (рекомендуется)**
   ```bash
   python -m venv venv
   
   # Для Windows:
   venv\Scripts\activate
   
   # Для Linux/Mac:
   source venv/bin/activate
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте конфигурацию**
   ```bash
   # Скопируйте пример конфигурации
   cp config.example.py config.py
   
   # Отредактируйте config.py в любом текстовом редакторе
   # Заполните обязательные поля: BOT_TOKEN и SUPER_ADMIN_ID
   ```

5. **Запустите бота**
   ```bash
   python main.py
   ```

### Быстрый запуск через скрипт (Windows)

Для пользователей Windows создан удобный скрипт запуска:

1. Отредактируйте `config.py` и заполните настройки
2. Дважды кликните по файлу `run.bat`
3. Бот запустится автоматически с активированным виртуальным окружением

## ⚙️ Конфигурация

### Основные настройки в `config.py`

```python
# 🔑 Обязательные настройки

# Токен бота от @BotFather в Telegram
BOT_TOKEN = "1234567890:ABCDEFGHIJKLMNOPQRSTUVWXYZ"

# Ваш Telegram ID (узнайте через @userinfobot)
SUPER_ADMIN_ID = "123456789"

# ID дополнительных администраторов (список Telegram ID)
INITIAL_ADMIN_IDS = ["987654321", "555555555"]

# 🌐 Настройки парсинга

# URL страницы с расписанием на сайте НТЭК
NTЕK_SCHEDULE_URL = "https://ntek.by/index.php/uchashchemusya/raspisaniya"

# ⏱️ Интервалы работы (в секундах)

CHECK_INTERVAL = 600      # Проверка обновлений: 10 минут
MESSAGE_COOLDOWN = 60     # Задержка между сообщениями пользователей: 1 минута
BROADCAST_COOLDOWN = 15   # Задержка между рассылками: 15 секунд

# 📁 Пути к файлам

DATA_FOLDER = "data"      # Папка для хранения данных

# ⚙️ Дополнительные настройки

ENABLE_AUDIT_LOG = True   # Включить ведение журнала аудита

# 💰 Настройки донатов

DONATION_TEXT = """
🌟 Поддержать разработчика:

Ваша поддержка помогает развивать бота и добавлять новые функции!
Спасибо за ваш вклад! 🙏
"""
```

### Получение необходимых данных

1. **Получение BOT_TOKEN:**
   - Напишите [@BotFather](https://t.me/BotFather) в Telegram
   - Используйте команду `/newbot`
   - Следуйте инструкциям, чтобы создать нового бота
   - Скопируйте выданный токен в формате `1234567890:ABCdefGHIjklMnoPQRstUvWxyz`

2. **Получение Telegram ID:**
   - Напишите [@userinfobot](https://t.me/userinfobot) в Telegram
   - Бот автоматически ответит с вашим ID
   - Скопируйте числовой ID

3. **Настройка администраторов:**
   - Получите ID всех, кто должен иметь доступ к админ-панели
   - Добавьте их ID в список `INITIAL_ADMIN_IDS`

### Файлы конфигурации

- **`config.py`** - Основной конфигурационный файл (не включается в Git)
- **`config.example.py`** - Пример конфигурации для новых пользователей
- **`.gitignore`** - Список игнорируемых файлов (включая `config.py`)

## 🔧 Разработка

### Зависимости проекта

Бот построен на современном асинхронном стеке:

```txt
aiogram==3.13.1          # Асинхронный фреймворк для Telegram Bot API
aiohttp==3.10.11         # Асинхронный HTTP-клиент для парсинга и запросов
aiofiles==24.1.0         # Асинхронная работа с файлами
beautifulsoup4==4.12.3   # Парсинг HTML страниц колледжа
certifi>=2023.7.22       # SSL-сертификаты
```

### Архитектура бота

1. **Ядро бота** (`main.py`) — инициализация хранилищ, запуск планировщика обновлений и Dispatcher.
2. **Асинхронный парсер** (`bot/services/parser.py`) — потоковый сбор и хэширование расписания с сайта НТЭК.
3. **Хранилище данных** (`bot/storage.py`) — потокобезопасная атомарная работа с файлами данных без СУБД.
4. **Обратная связь** (`bot/handlers/feedback.py`) — изолированный конечный автомат (FSM) с быстрыми ответами для админов.
5. **Архив расписаний** (`bot/handlers/archive.py`) — открытый доступ к архиву для учащихся и педагогов.

### Расширение функциональности

Чтобы добавить новую команду:

1. Добавьте обработчик в `main.py`:
```python
@bot.message_handler(func=lambda message: message.text == 'Новая команда')
def new_command(message):
    # Ваш код здесь
```

2. Добавьте кнопку в клавиатуру (если необходимо):
```python
# В функции get_main_keyboard или admin_keyboard
keyboard.row('Новая команда')
```

### Тестирование изменений

1. Активируйте виртуальное окружение
2. Запустите бота в тестовом режиме:
```bash
python main.py
```
3. Протестируйте новую функциональность через Telegram
4. Убедитесь, что нет ошибок в консоли

## 📊 Административные функции

### Доступ к админ-панели

1. Стать администратором можно двумя способами:
   - Быть добавленным в `INITIAL_ADMIN_IDS` в конфигурации
   - Быть добавленным главным администратором через бота

2. Доступ к админ-панели:
   - Отправьте команду `/admin`
   - Или нажмите кнопку "Админ-панель" в главном меню (если вы администратор)

### Функции админ-панели

#### 📊 Статистика
Показывает:
- Количество пользователей
- Количество администраторов
- Статистику сообщений (всего/неотвеченных)
- Статус файлов расписаний

#### 📢 Рассылка
- Отправка текстовых сообщений всем пользователям
- Отправка фотографий с подписями
- Защита от частых рассылок (ограничение 1 раз в 15 секунд)
- Отчет об успешной доставке

#### 🔄 Обновление расписаний
- Ручное обновление расписания звонков (фото)
- Ручное обновление расписания от учащихся (фото)
- Автоматическое обновление основных расписаний с сайта

#### 📨 Модерация сообщений
- Просмотр последних 10 сообщений от пользователей
- Фильтрация по статусу (отвечено/не отвечено)
- Ответ пользователям (текст, фото, голосовые, видеокружки)
- Отметка сообщений как отвеченных

#### 👥 Управление администраторами
- **Только для главного администратора**
- Добавление новых администраторов по ID
- Удаление существующих администраторов
- Просмотр текущего списка администраторов

#### 📊 Аудит
- Просмотр последних 20 административных действий
- Экспорт полного журнала аудита в JSON
- Информация о времени, администраторе и действии

#### 📁 Файлы
- **Только для главного администратора**
- Экспорт файлов данных:
  - `audit_log.json` - журнал аудита
  - `user_names.json` - информация о пользователях
  - `admins.json` - список администраторов

### Система аудита

Все действия администраторов записываются в журнал:

```json
{
  "timestamp": "2024-01-15 14:30:00",
  "admin_id": 123456789,
  "admin_username": "@username",
  "action": "рассылка",
  "details": "Тип: фото, охват: 150/200 пользователей"
}
```

## ❓ Часто задаваемые вопросы

### ❔ Как добавить нового администратора?

1. Главный администратор должен открыть админ-панель
2. Выбрать "➕ Добавить админа"
3. Ввести ID пользователя (число)
4. Пользователь получит уведомление о новых правах

### ❔ Почему бот не отправляет уведомления об обновлениях?

Возможные причины:
1. Бот не запущен или упал
2. Изменилась структура сайта НТЭК
3. Проблемы с интернет-соединением
4. Пользователь заблокировал бота

Проверьте:
- Логи бота на наличие ошибок
- Файлы расписания в папке `data/`
- Доступность сайта НТЭК

### ❔ Как сбросить данные бота?

1. Остановите бота (Ctrl+C в консоли)
2. Удалите папку `data/`
3. Перезапустите бота
4. Бот создаст новую чистую папку `data/`

**Внимание:** Это удалит всех пользователей, сообщения и настройки!

### ❔ Бот показывает ошибку "Config.py не найден"

Решение:
```bash
cp config.example.py config.py
# Отредактируйте config.py, заполнив BOT_TOKEN и SUPER_ADMIN_ID
```

### ❔ Как получать обновления бота?

1. Остановите бота
2. Получите последние изменения:
```bash
git pull origin main
```
3. Установите обновленные зависимости (если нужно):
```bash
pip install -r requirements.txt
```
4. Запустите бота снова

### ❔ Можно ли запустить бота на сервере?

Да, бот может работать на любом сервере с Python:

1. **На VPS/VDS:**
   ```bash
   # Установите Python и Git
   sudo apt update
   sudo apt install python3 python3-pip git
   
   # Клонируйте и запустите бота
   git clone https://github.com/playaemor/ntek-schedule-bot.git
   cd ntek-schedule-bot
   pip3 install -r requirements.txt
   python3 main.py
   ```

2. **Используя systemd (для автозапуска):**
   Создайте файл `/etc/systemd/system/ntek-bot.service`:
   ```ini
   [Unit]
   Description=NTЕK Schedule Telegram Bot
   After=network.target
   
   [Service]
   Type=simple
   User=username
   WorkingDirectory=/path/to/ntek-schedule-bot
   ExecStart=/usr/bin/python3 /path/to/ntek-schedule-bot/main.py
   Restart=on-failure
   
   [Install]
   WantedBy=multi-user.target
   ```
